# Public snapshot contract

This repository is a supporting, audited source/test snapshot. It has no production
or private-repository authority. Keep SNAPSHOT.json byte provenance current when
making an explicitly authorized change. Do not import private history, campaign
reports, credentials, customer data, operational evidence or private dependencies.
CI must remain self-contained with a read-only token and standard hosted runners.
Public CI success is distinct from source acceptance, merge, deployment and use.
